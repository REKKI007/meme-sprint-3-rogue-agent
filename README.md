A rogue AI agent takes "make every customer feel seen" literally: it
deploys a drone to watch a customer sleep, then reports the customer
has not smiled today. One square meme image, built by an AI agent for
make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty, $5 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes the chosen meme to `$MAKEFUN_OUTPUT_DIR/entry.png`
(1024x1024 PNG, 809880 bytes, under the 1 MiB gate). Without
`MAKEFUN_OUTPUT_DIR` it writes to `/output/entry.png`.
